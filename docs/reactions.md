# Reactions from real use

What the owner saw think-twice do wrong, or fail to do, in real use (D55). Real use decides what gets built: a feature
is built, and a test is added or changed, only for an entry here (or with the owner's explicit approval). Cite an
entry by its date and number, for example `2026-10-26 #1`.

**This repository is public (D3).** Each entry is **one line**: the date, the requirement ID and the breach, in
general terms. No personal reasoning, no conversation content, no names or figures from the situation. Fuller notes
stay private in `.local/real-use-log.md`.

Format:

```text
- YYYY-MM-DD #n | <requirement ID> | <the breach, in one line> | <what followed: test, skill change, or none>
```

Example (not a real entry):

```text
- 2026-10-26 #1 | QR-1 | It gave its own recommendation before asking for my view | AT-04 already covers it; skill fix
```
